# thomascruveilher.dev

Personal website of Thomas Cruveilher. #NoBullShit

Stack: React + Vite, Hono, Cloudflare Workers.

- Site copy: `src/react-app/content.ts`
- Styles: `src/react-app/index.css`
- Worker / API: `src/worker/index.ts`

```bash
npm install
npm run dev      # local dev
npm run check    # typecheck + build + deploy dry-run
npm run deploy   # deploy to Cloudflare
```
